PVZ backup

Частное приложение одного владельца. Его сервер каждую ночь шифрует резервную копию своих данных и кладёт её в одну папку на Google Диске этого же владельца.

Приложение запрашивает только право drive.file: доступ к файлам, которые оно создало само. Остальные файлы Диска ему не видны. Посторонние пользователи приложением не пользуются.

A private single-owner application. Its server encrypts a nightly backup of its own data and stores it in one folder on the same owner's Google Drive, using only the drive.file scope.
